# Эмулятор языка оболочки ОС

**Дисциплина:** Конфигурационное управление
**Группа:** ИКБО-32-25
**Вариант:** 26
**Выполнено:** Этап 1 (REPL)

## 1. Общее описание

Эмулятор языка оболочки ОС — приложение с графическим
интерфейсом, которое имитирует работу командной строки
UNIX-подобной операционной системы.

На **этапе 1** создан минимальный прототип: диалог с
пользователем уже поддерживается, а большинство функций
представляют собой заглушки.

Приложение реализовано на **Python**, графический
интерфейс — **Tkinter** (входит в стандартную поставку
Python, внешних зависимостей нет).

### Что умеет прототип

- Окно-терминал: тёмная область вывода и строка ввода,
  команда выполняется по клавише `Enter`, введенная строка
  эхо-выводится, как в настоящем терминале.
- Заголовок окна формируется из **реальных данных ОС**, в
  которой исполняется эмулятор, например
  `Эмулятор - [ivanov@MIREA-PC]`:
  пользователь — `getpass.getuser()`, имя узла —
  `socket.gethostname()`.
- Простой парсер: ввод разделяется на команду и аргументы по
  пробелам (и табуляциям).
- Команды-заглушки `ls` и `cd`: выводят своё имя и
  переданные аргументы.
- Команда `exit` завершает сеанс и закрывает окно.
- Обработка ошибок (вывод красным цветом):
  - неизвестная команда — `sh: <имя>: command not found`;
  - неверные аргументы — `exit: too many arguments`
    (у `exit` не может быть аргументов).
- Пустая строка игнорируется — как в настоящем shell.

### Структура проекта

```
shell-emulator/
├── README.md            # этот файл
├── .gitignore
├── Makefile             # цели run, demo, test
├── run.sh               # запуск на Linux/macOS
├── run.bat              # запуск на Windows
├── src/
│   ├── __init__.py
│   ├── core.py          # парсер и диспетчер команд (без GUI)
│   └── main.py          # графический интерфейс (Tkinter)
├── tests/
│   ├── __init__.py
│   ├── test_parser.py   # тесты парсера
│   ├── test_core.py     # тесты команд и обработки ошибок
│   └── test_main.py     # тесты аргументов командной строки
└── demo/
    └── demo_script.txt  # сценарий автоматической демонстрации
```

Логика (парсер, команды, ошибки) вынесена в `src/core.py` и
не зависит от Tkinter — поэтому её полностью покрывают
юнит-тесты, а графический слой остаётся тонким.

## 2. Описание всех функций и настроек

### Команды

| Команда | Аргументы | Поведение на этапе 1 |
| --- | --- | --- |
| `ls` | любые | заглушка: выводит имя и аргументы, например `ls: args: -la, /home` |
| `cd` | любые | заглушка: выводит имя и аргументы, например `cd: args: ..` |
| `exit` | нет | завершает сеанс, окно закрывается |

### Обработка ошибок

| Ситуация | Сообщение |
| --- | --- |
| неизвестная команда | `sh: foobar: command not found` |
| `exit` с аргументами | `exit: too many arguments` |
| пустая строка | игнорируется, повторяется приглашение ввода |

### Настройки (аргументы командной строки)

| Аргумент | Назначение |
| --- | --- |
| `--demo` | автоматический показ: эмулятор сам «вводит» команды из `demo/demo_script.txt` с задержкой — удобно для записи экрана |

Других настроек на этапе 1 нет: параметры командной строки
(путь к VFS и путь к стартовому скрипту) появятся на этапе 2.

## 3. Команды сборки и запуска тестов

Требования: Python 3.9+ (на Linux при отсутствии Tkinter —
`sudo apt install python3-tk`); для тестов — `pytest`.
Сборка не требуется: проект интерпретируемый, артефактов
нет.

| Действие | Команда |
| --- | --- |
| запуск (интерактивно) | `./run.sh` (Linux/macOS) или `run.bat` (Windows), `make run` |
| запуск (демо-режим) | `./run.sh --demo` или `make demo` |
| запуск напрямую | `python3 -m src.main` |
| запуск тестов | `make test` или `python3 -m pytest -q` |

## 4. Примеры использования

### Интерактивный сеанс

Сеанс ниже воспроизводится в окне эмулятора; ошибки
(`sh: ...` и `exit: too many arguments`) выводятся
красным, приглашение — зелёным:

```
user@hostname:~$ ls
ls: no args
user@hostname:~$ ls -la /home/user
ls: args: -la, /home/user
user@hostname:~$ cd /var/log
cd: args: /var/log
user@hostname:~$ foobar
sh: foobar: command not found
user@hostname:~$ exit 1
exit: too many arguments
user@hostname:~$ exit
session ended
```

После команды `exit` окно закрывается.

### Демо-режим (показ на семинаре)

```
./run.sh --demo
```

Эмулятор сам «вводит» команды из `demo/demo_script.txt`
(комментарии `#` пропускаются), последовательно показывая:
работу заглушек `ls`/`cd` без аргументов и с аргументами,
обе ошибки и завершение сеанса. Режим рассчитан на запись
экрана; после последней команды `exit` окно закрывается
само.
